# 微步情报 (dsh-threatbook-intel)

DSH Harness 插件：把「微步在线云 API」接进 Web 界面与对话。

## 安装

**方式一：压缩包 (推荐，无需任何账号)**

从 [Releases](https://github.com/Lingggao/LGSRC/releases) 下载 `threatbook-intel-*.zip`，解压到任意目录，然后在 DSH「插件 → 添加插件」中填入解压后**含 `package.json` 的那一层目录**的绝对路径。

**方式二：Git 仓库**

```bash
git clone https://github.com/Lingggao/LGSRC.git
```

在「添加插件」中填 `<克隆目录>/dsh-plugins/threatbook-intel` 的绝对路径。

**方式三：npm (可选，发布后才有)**

在「添加插件」中填包名 `dsh-threatbook-intel`。

> 三种方式效果相同，选一种即可。安装后**刷新页面**，「设置 → 微步情报」里粘贴 API Key (先把本机出口 IP 绑定到微步「我的 KEY」)。

## 隐私边界

- 只访问 `api.threatbook.cn`(查询) 与若干公网 IP 探测服务 (仅取本机出口 IP，可用 `THREATBOOK_EGRESS_URLS` 覆盖)。
- API Key 只写入本机 `<profile>/plugin-data/threatbook-intel/apikey.json`(0600)，
  不上传、不同步、不进入模型上下文。
- 包内不含任何密钥；每个使用者的 Key 都由其本机自行填写。

## 能力

1. **启动即显示本机 IP**：输入框下方一条状态条固定三行——产品名 + 出口 IP + 复制 / 绑定；API Key + 最近查询；AI 总结 / 打开报告 / 打开目录。
   出口 IP 默认打码 (如 `61.***.***.17`)，点「显示」可切换；读不到 Key 时展开为三步引导卡片。
2. **自动打开绑定页**：未配置 Key 时自动在浏览器打开
   <https://x.threatbook.com/v5/serviceCenter?tab=myKey> 并列出绑定步骤 (每进程只自动打开一次，也可点「绑定」手动打开)。
3. **Key 只存本机**：写入 `<profile>/plugin-data/threatbook-intel/apikey.json`(0600)，
   不上传、不同步、不写入会话日志；设置页显示文件路径，可随时清除。
4. **设置页五节**：出口 IP / 绑定访问 IP / API Key / 接口权限 / 最近查询；
   API Key 徽章按状态取色 (已配置绿、未配置黄、校验未通过红)，保存后自动校验；保存与测试按钮带加载态。
5. **自动识别指标并全量查询**：对话里直接贴 IP / 域名 / MD5-SHA1-SHA256 / URL / CVE-XVE 等，模型会调用
   `threatbook_lookup`，插件按类型执行**尽可能全**的接口组合：

   | 类型 | 接口 |
   | --- | --- |
   | IP | `ip/query`、`scene/ip_reputation`、`ip/adv_query` |
   | 域名 | `domain/query`、`domain/adv_query`、`domain/sub_domains`、`scene/ioc`、`scene/domain_context` |
   | Hash | `file/report`(summary+multiengines+signature+static+network+dropped+pstree+strings)、`file/report/multiengines` |
   | URL | `url/report`，无报告时自动 `url/scan` 并轮询报告 |
   | 漏洞 | `vuln`(VPR/CVSS/PoC/修复方案/补丁/在野利用) |

6. **结论先行**：每次查询附带研判提示——证据等级、0-100 威胁评分与 P0-P3 优先级、判定来源接口、
   情报新鲜度、攻击链位置与对应 ATT&CK；无权限接口会被标注为「无法判定」而不是当作安全。
   即使部分接口没权限，已有的恶意标签 (银狐 / C2 / 勒索等) 也不会被忽略或降级。
   确认无权限的接口在本次会话内自动跳过 (重启后重试)，设置页「接口权限」会列出这些接口。
7. **会话隔离**：状态条只显示**当前会话**的最近一次查询，AI 总结也只使用本会话的记录；
   设置页展示「所有会话最近一次」，避免不同会话互相串台。
8. **报告落盘**：每次查询把**完整原始 JSON** 与**完整 Markdown 报告**写入报告目录
   (默认 `threatbook-reports/`)，文件名统一以 `LGSRC-` 开头，返回值里给出路径。
9. **报告目录管理**：设置页「报告存储」显示当前目录，可复制路径、在文件管理器打开、改到任意目录；
   改到工作区之外时需要显式确认授权。切换目录时会询问是否把旧报告**复制 / 移动 / 保持原样**。
10. **清理与撤销**：列出当前目录中由本插件写出的报告 (按内容指纹识别，不误删其他文件)，
    可逐项勾选后移入同目录下的 `.LGSRC-trash` 回收站，删除后本次会话内可撤销；换目录后仍可撤回到原目录。
    回收站保留期可选 7 天 / 30 天 / 永久，也可以手动清空 (需二次确认，清空后不可撤销)。
11. **多个后续选项**：工具返回时会列出「简要总结 / 打开完整 MD / 深入某字段」供用户选择；
    同时提供 `threatbook_status` 查看 IP、Key、绑定地址与最近一次查询。
12. **关于与更新**：设置页「关于」显示机构简介、当前版本与发布日期，提供门户网站与 GitHub 主页入口，可一键检查 GitHub Releases
    是否有新版本并给出下载与覆盖安装方式；反馈入口会把 `ling@lghub.org` 复制到剪贴板。

## 界面预览 (开发用)

插件面板有 8 种状态，正常只能看到自己当前那一种。开发时**直接点击插件名称中间的「·」**即可循环切换 (无需改地址栏)，循环一圈回到真实数据；也可以在 GUI 地址后追加 `?tb=<场景>` 直接进入指定状态 (地址已有参数则用 `&tb=`)：

| 场景 | 用途 |
| --- | --- |
| `?tb=unconfigured` | 未配置 Key 的三步引导卡片 |
| `?tb=configured` | 已配置、无查询记录的常态 |
| `?tb=last` | 带「最近查询」与操作按钮 |
| `?tb=reports` | 自定义报告目录、工作区外已授权、回收站非空 |
| `?tb=empty` | 已配置但从未查询过 |
| `?tb=notice` | 带一条错误提示 |
| `?tb=loading` | 首次加载中 |
| `?tb=error` | 本机服务不可用 |

进入后面板顶部会出现一条虚线预览条，可直接点按钮切换场景，点「退出预览」回到真实数据；切换即时生效，不刷新页面。预览模式**完全使用假数据**，所有写操作 (保存 / 清除 Key、打开报告) 都会被拦截，不会碰到真实 Key 与本机文件。

## 配置 (可选环境变量)

| 变量 | 说明 |
| --- | --- |
| `THREATBOOK_KEY_FILE` | 覆盖 Key 文件路径 |
| `THREATBOOK_EGRESS_URLS` | 逗号分隔的公网 IP 探测服务，默认 ipinfo.io / ifconfig.me / api.ip.sb / myip.ipip.net / api.ipify.org |

## 数据边界

- 只访问 `api.threatbook.cn`(查询) 与上面列出的 IP 探测服务 (仅取本机出口 IP)；
  手动点「检查更新」时会访问 `api.github.com` 拉取 Releases 列表，不发送 Key 或本机信息。
- API Key 不进入模型上下文：UI 通过本机回环路由 `/threatbook/*` 与 Host 通信，POST 强制 `application/json`。

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 接口权限 | 个人账号通常只有 IP 信誉、失陷检测与文件相关接口；域名分析、URL、漏洞等需要企业权限，无权限时结论会标注「无法判定」而不是「安全」 |
| 配额 | IP 信誉 50 次/天、文件相关 300 次/天、`scene/dns` 按月计算；「测试连通性」与保存后自动校验查询一个 SHA256 样本，各占 1 次文件查询额度，不动 IP 额度 |
| 指标格式 | 支持 IPv4/IPv6、域名 (ASCII)、MD5/SHA1/SHA256、带协议的 URL、CVE/XVE/CNVD 等编号；暂不支持 `IP:端口`、中文域名 (IDN) |
| 权限缓存 | 确认无权限的接口在本次进程内跳过，重启 DSH 后重新尝试 |
| 报告目录 | 目录设置是全局的，所有会话共用一份；工作区外的目录需要一次显式授权 |
| 回收站 | 删除是软删除，文件移到同目录的 `.LGSRC-trash`；过期清理在 DSH 启动或每小时轮询时执行，DSH 关闭期间不会清理 |
| 检查更新 | 依赖 GitHub 可访问；未认证的 GitHub 接口有频率限制，结果缓存 10 分钟，失败时只提示错误、不影响查询 |

## 界面约定

- 按钮高度固定 28px；宽度分两档：
  1-5 字统一用 92px (原 4 字时的宽度)，字数不同也同宽，5 字略挤；
  6 字以上按 `44 + 12 × 字数` px 自动加宽 (空格也算一个字)。
  加载指示器的空间已预留；5 字按钮在加载时临时放宽到 104px，避免文字被裁切。
- 输入框与按钮同高 28px，并排出现时不出现高低差。

## 文案约定

改动界面时请沿用下表写法，避免同一个概念出现多种叫法：

| 概念 | 固定写法 | 不要写成 |
| --- | --- | --- |
| 产品名 | `LGSRC · 微步情报查询` | 微步情报、LGSRC 微步情报 |
| 凭据 | `API Key` | Key、密钥、微步 API Key |
| 公网地址 | `出口 IP` | 公网出口 IP、外网 IP |
| 本机地址 | `网卡 IP` | 内网 IP、本地 IP |
| 指标类型 | `IP / Domain / Hash / URL / CVE` | 域名、文件 Hash、漏洞编号 |
| 微步控制台页面 | `我的 KEY` | 我的 Key (该页面名本身是全大写，属专有名词) |
| 打开报告所在目录 | `打开文件夹` | 打开目录、打开报告目录 |
| 最近查询操作 | `打开报告` | 打开完整 MD 报告 |
| 排版 | 中英文之间、英文括号前后各留一个空格 (中文、数字、字母都算) | 中英文粘连、括号紧贴文字、数字或字母后紧跟括号 |
