# 变更记录

本文件记录 `threatbook-intel` 插件的版本变化。发版时在顶部新增一节。

## 1.8.6 — 2026-10-26

报告存储分区的操作顺序调整，纯界面排布，行为不变。

**界面**
- 按「当前目录 → 回收站」重排：清理报告按钮紧跟存储目录，不再排在回收站设置之后
- 回收站改为独立一组：路径 → 现有数量 → 保留策略 → 清空回收站，组前加分隔线
- 「清空」改名为「清空回收站」，避免和「清理报告」混淆
- 「清理报告」按钮固定 116px (6 字宽)，报告数量变化、展开/收起、扫描过程中都不会变宽
- 存储目录路径独占一行，复制路径 / 打开文件夹 / 更改目录移到下一行，避免长路径挤压按钮
- 回收站路径同样独占一行，复制路径 / 打开回收站移到下一行，与存储目录保持同一种排布
- 清理说明改为「自动识别文件内容，仅清理本插件撰写的报告」
- 「选择文件夹…」去掉省略号，回到 1-5 字按钮的统一宽度 92px
- 清空回收站确认文案改为「确认清空？回收站中的 N 个文件将被永久删除，无法撤销。」

## 1.8.5 — 2026-10-26

按钮与输入框的尺寸规则统一，界面文案与外链收敛，宿主侧合并重复实现；行为与数据不变。

**界面**
- 所有按钮固定 28px 高，不再区分大小号高度
- 按钮宽度改为两档：1-5 字统一 92px (原 4 字宽度)，6 字以上按 `44 + 12 × 字数` px 自动加宽；同字数按钮 (含中英文混排) 宽度完全一致
- 5 字按钮加载时临时放宽到 104px 容纳指示器，静态宽度仍是 92px；取消大小号按钮的内边距差异
- 输入框与按钮同高 28px，报告存储的目录编辑行里输入框、选择文件夹、保存按钮齐平
- 步骤卡片操作区高度随按钮调整，首次配置的三步引导不再出现按钮高矮不一
- 修复插件热重载时旧样式表未被覆盖、导致界面沿用旧按钮尺寸的问题
- 统一「打开文件夹」「打开报告」措辞，移除「打开目录 / 打开报告目录 / 打开完整 MD 报告」三种旧写法
- 样式令牌收敛：摘要框、Hero 小条、错误提示、强调标题、编号圆环统一走令牌；步骤卡、分节头、预览条不再散落硬编码字号与间距
- 移除按钮已无视觉效果的大小号变体，按钮只剩一套规格
- 宿主侧合并重复的 HTTP GET 与目录写探测实现，网络与目录行为不变
- 外链统一为 ExternalLink 组件：关于页三处与绑定页地址都带「新窗口」标识与可读名称，不再有的链接标、有的没标

## 1.8.4 — 2026-10-26

研判口径、总结提示词、关于页与报告存储界面更新。合并自 1.8.3 (未单独发布)；升级自 1.8.2，报告文件与配置均无需迁移。

**研判与总结**
- 恶意标签优先：接口只返回标签、没有返回 `is_malicious` 时，银狐 / C2 / 勒索 / 木马等标签直接支撑「恶意」结论 (评分不低于 55)，不会再因为缺少接口权限掉到 P3
- 标签与判定冲突时 (接口判非恶意但标签为木马等) 按可疑处理，并在研判提示里提示人工复核
- 「无法判定」只在既没有任何标签、关键接口又都不可用时成立
- AI 总结改为 200-260 字的四段式 (结论 / 依据 / 处置 / 不确定)，去掉角色设定和固定长模板，直接给可贴进工单的结论
- 首次查询的回答契约同步收紧：决策优先，证据标注接口字段，C2 单独成段并给逐条封禁清单

**关于**
- 设置页新增「7 关于」：机构简介、当前版本与发布日期
- 「检查更新」对比 GitHub Releases 里的本插件版本，有新版本时给出版本号、发布日期与下载 / 覆盖安装方式；结果缓存 10 分钟，避免频繁请求
- 「Bug 反馈与建议」复制 `ling@lghub.org` 到剪贴板并提示邮件联系；同时提供项目主页与更新日志链接
- 新增门户网站链接 `https://www.lgsrc.cn` 并排在第一位；原「项目主页」更名为「GitHub 主页」
- 版本行合并为「当前版本 v1.8.3 · 发布于 2026-10-26」，去掉右侧重复的机构名
- 「6 报告存放」更名为「报告存储」；存储目录的默认 / 自定义提示、授权确认、迁移取消与回收站按钮文案一并理顺
- 检查更新只访问 `api.github.com`，不发送 API Key 或本机信息
- 外链统一标注「在新窗口打开」，悬停出现下划线；检查更新失败时不再同时显示「已是最新版本」
- 报告存储：默认状态不再重复「未设置时使用默认目录」；清理面板收起时受控区域保留但隐藏，读屏始终能找到 aria-controls 目标
- 交互：按钮补按下反馈，报告勾选框补品牌色焦点环，避免键盘操作时看不出焦点

## 1.8.2 — 2026-10-26

报告目录管理与界面审查收口。合并自 1.8.0、1.8.1 (均未单独发布)；报告文件格式与目录结构不变，从 1.7.3 升级无需迁移。

**报告存放**
- 设置页新增「报告存放」：显示当前保存目录，支持复制路径、在文件管理器打开、改到任意目录
- 目录设置全局生效，默认 `<工作区>/threatbook-reports`；改到工作区之外时需一次显式授权，保存前会做可写性探测
- 换目录时可选「复制到新目录 / 移动到新目录 / 旧报告保持不变」，也可以随时恢复默认目录
- 已授权的工作区外目录不再常驻红色告警，只在真的还差一次授权时提示
- 新报告仍以 `LGSRC-` 开头；同一秒对同一指标查两次不再互相覆盖 (文件名带随机后缀)

**清理与回收站**
- 按内容指纹识别报告，同目录里的代码、文档、图片不会被误删；旧命名的历史报告同样能识别
- 清理前先列出报告清单，支持逐项勾选与全选 / 全不选，默认全选
- 删除是软删除：文件移入 `<报告目录>/.LGSRC-trash`，本次会话内可撤销；换目录后仍可撤回到原目录
- 回收站保留期可选 7 天 / 30 天 / 永久，过期批次在 DSH 启动或每小时轮询时清理
- 新增「清空回收站」：二次确认后永久删除，不可撤销；界面上同时显示回收站路径与占用

**界面与可访问性**
- 「清除」API Key 改为二次确认，误点后不必回微步后台重新取 Key
- 目录为空时就地报错并关联到输入框 (aria-describedby / aria-invalid)；路径未变化时给出提示，不再静默关闭编辑态
- 「清理报告」改为展开器 (aria-expanded / aria-controls)，扫描期间显示加载态，不再用危险色误导
- 保留期按钮补 aria-pressed；打码开关、报告列表、最近查询摘要补可见焦点环并支持键盘操作
- 状态提示修正 role 与 aria-live 冲突；开发用的预览入口退出 Tab 顺序与无障碍树
- 报告时间与查询时间统一为 `YYYY-MM-DD HH:mm:ss`；网卡列表补空态

**稳定性与安全**
- 最近查询按会话隔离：状态条只显示本会话记录，设置页显示「所有会话最近一次」，AI 总结只读取本会话记录
- 无效 Key、白名单未绑定不再被误报成「该类型接口均无权限」；网络失败与权限不足分开显示
- 本地目录改用 `explorer.exe` 直接打开，避免 cmd 解析目录名中的特殊字符
- 删除、撤销、清空都按当前目录或已授权目录校验；选中的报告已不存在时明确报错而不是假装成功
- 报告目录扫描加 5 秒缓存，状态轮询不再反复读取全部报告文件
- `settings.json` 改为原子写入，避免中途崩溃写坏配置

**测试**
- 新增报告面板契约测试 (22 项)：授权状态、选中态、展开态、危险按钮、焦点挂点与二次确认
- 渲染冒烟新增 `reports` 场景 (自定义目录 / 工作区外已授权 / 回收站非空)
- `scripts/test-all.mjs` 纳入契约测试步骤；主逻辑单测、8 场景渲染冒烟与 UI 一致性审计全部通过

## 1.7.2 — 2026-10-25

Key 校验改用文件样本。

- 「测试连通性」与保存后的自动校验不再查询 IP 信誉 (50 次/天)，改为查询一个公开的 SHA256 测试样本 (EICAR) 的文件报告，占用文件查询额度 (300 次/天)，普通账号明显更经用
- 校验只取 `summary` 一个字段，单次调用开销最小；实测 290ms 返回 `response_code=0`
- 频率或配额受限时改为提示「Key 有效但受限」，不再误判为 Key 无效
- 额度或频率受限时，API Key 徽章单独显示蓝色「额度用尽」，与未配置的黄色区分；悬停可看具体原因
- 徽章在颜色与文字之外补 `aria-label`，读屏软件能读到完整原因，不再依赖鼠标悬停
- 没有文件报告接口权限时，提示「Key 可能仍然有效」并说明无法完成校验，不再让人以为 Key 失效
- 绑定步骤三张卡的标题与说明行间距统一：说明行固定 24px 行高，绑定按钮改为小尺寸，不再把第一张卡的说明文字顶下去
- 设置页按钮提示与输入框说明、README 配额说明同步改为文件查询额度

**设置页**
- 分节编号 1–5 连续；接口权限一栏常驻显示，不再因无记录而整节消失

- 绑定步骤三张卡统一两行：标题行 + 说明行，按钮位于说明行右侧
- 出口 IP 增加「探测于 HH:MM:SS」；表格列名「网卡」改为「接口」；「测试连通性」标注额度消耗
- 网卡列表由自动布局表格改为固定列宽网格：数据行显式声明 12px 字号 (此前改为网格后继承了宿主默认字号，显得偏大)；「操作」表头与每行「复制」按钮同列居中，严格同轴；长 IPv6 地址自动省略并保留悬停查看

**状态条**
- 查询后固定三行：标题 + 出口 IP + 复制 / 绑定；API Key + 最近查询；AI 总结 / 打开报告 / 打开目录

- 出口 IP 默认打码，点注释可切换；绑定步骤中的 IP 同样跟随打码状态

**数字与判断**
- 徽章、优先级、无权限接口均按语义取色，P0 红、P1 黄
- 无权限接口在会话内记住并跳过，查询结果里注明跳过项

**稳定性**
- AI 总结注入的消息改用规范 UUID 并冻结，避免快速连点时的消息身份冲突
- 全部接口无权限时，兜底执行的那一个不再同时出现在「已跳过」列表里
- 保存 Key 的说明补上「会自动校验一次，占用一次 IP 信誉额度」

## 1.6.0 — 2026-10-25

省额度：无权限接口在会话内不再重复调用。

- **权限记忆**：接口返回「没有访问接口权限」后记入本次会话，后续同类查询直接跳过，不必每次去撞墙；接口恢复正常会立即解除记忆
- **计划过滤**：查询前按已知权限过滤接口集合，全部无权限时只保留一个做探测，避免整批无效调用
- **URL 早退**：`url/report` 无权限时立即返回，不再进入提交分析 + 多轮轮询的流程
- **结果说明**：查询结果里注明「已跳过本次会话中确认无权限的接口」，重启 DSH 后会重新尝试
- **设置页新增「接口权限」分节**：列出当前会话确认无权限的接口，方便判断该升级套餐还是换情报源
- 说明：跳过只在进程内生效，不写盘，也不影响有权限的接口

## 1.5.0 — 2026-10-25

适配部分账号只开通了部分接口权限的情况。

- **权限矩阵**：每类指标标明「能定性」所依赖的接口 (IP：ip/query + reputation；Domain：domain/query + scene/ioc；Hash：file/report + multiengines；URL：url/report；CVE：vuln)，判定时逐接口合并，任一可用即可定性
- **无法判定与无记录分开**：当某类指标的关键接口全部无权限或失败时，结论写「权限不足，无法判定」，不再输出「无情报记录」，评分也不再用低分暗示安全
- **全失败文案**：所有接口都因无权限失败时，直接说明「该类型接口均无权限」，而不是笼统的查询失败
- **多引擎兜底**：样本接口无权限但多引擎接口可用时，用多引擎共识 (≥5 家报毒) 支撑判定，并在提示里注明来源是多引擎而非微步单点
- **判定来源可见**：提示行新增「判定来源 / 无权限」明细，摘要结论标注来自哪个接口
- **提示词**：加入两条规则——权限缺失时必须写「权限不足，无法判定」；部分缺失但有可用判定时，以可用判定为准并说明把握度折损

## 1.4.2 — 2026-10-25

修复“微步已判恶意却被打成 P3 低危”的问题。
