# 变更记录

本文件记录 `threatbook-intel` 插件的版本变化。发版时在顶部新增一节。

## 1.0.5 — 2026-10-24

界面细节打磨，功能不变。

- **层级区分**：设置页步骤卡的序号改为 16px 空心描边（分节标题保持 18px 实心），嵌套关系一眼可辨；网格最小宽度 230px → 190px，三张步骤卡更易排成一行
- **长指标截断**：状态条里的 64 位 hash 改为首 12 位 + 末 8 位，完整值放入悬停提示，不再撑宽整行；设置页的同类字段允许换行
- **绑定页地址**：由裸链接改为“标签 + 链接 + 复制”一行
- **按钮宽度**：统一最小宽度 54px 并居中，复制后文案变为“已复制”时整行不再位移
- **键盘焦点**：恢复输入框的原生焦点框，键盘操作可定位
- **简介压缩**：简介再压到 96 字，适配插件列表的窄栏显示

## 1.0.4 — 2026-10-24

简介与排版统一，功能不变。

- **简介重写**：从“罗列功能”改为“使用路径”——展示出口 IP 并一键复制 → 引导绑定微步「我的 KEY」→ API Key 只存本机 → 粘贴指标即查询并生成报告；结尾保留“由 LGSRC 维护”，不再重复组织全称
- **简介用词统一**：指标类型与界面一致，改为 `IP / Domain / Hash / URL / CVE`，不再出现“域名”“文件 Hash”“漏洞编号”
- **标点统一**：插件内全角括号全部改为半角 `()`，共 194 处，覆盖界面文案、工具提示、README 与 CHANGELOG
- **排版规则**：中英文之间、英文括号外侧统一补一个空格（共 72 处），并在 README 的文案约定表补充这条约束

## 1.0.3 — 2026-10-24

界面重做，功能与接口不变。

- **按钮可识别**：复制 / 绑定等次级按钮改为实体底色 (`bg-layer-2` + 1px 边框 + 8px 圆角)，鼠标悬停时底色加深、边框提亮，不再与背景混在一起
- **状态条分区**：出口 IP、API Key、最近查询三组之间改用 1px 竖线分隔，取代原来的 `|` 字符，层次更清楚
- **Key 显示格式**：改为 `API Key: 04a6***32c8` —— 保留前 4 位与后 4 位、中间三位星号，前缀使用英文冒号
- **名称统一**：面板、设置页、新对话胶囊统一为 `LGSRC · 微步情报查询`
- **未配置态**：改为三张步骤卡 (复制 IP / 添加白名单 / 保存 Key)，每张卡带序号与一句说明
- **文案统一**：指标类型一律用英文缩写 (`IP / Domain / Hash / URL / CVE`，不再出现“域名”“漏洞编号”)；名称统一为 `LGSRC · 微步情报查询`；凭据一律写作 `API Key`(不再出现裸“Key”“微步 API Key”)；“公网出口 IP”统一为“出口 IP”
- **界面预览 (开发用)**：在 GUI 地址加 `?tb=<场景>` 可用假数据查看 7 种界面状态 (未配置 / 已配置 / 有最近查询 / 无记录 / 带提示 / 加载中 / 服务不可用)，顶部预览条可一键切换；预览模式下所有写操作被拦截，不接触真实 API Key
- **状态灯**：状态指示改为 7px 实心圆 + 3px 柔和光晕 (`color-mix` 22% 底色)；未配置状态改用 9px 空心圆环，与“已就绪”一眼区分
- **字体统一**：全插件使用界面默认字体，不再使用等宽字体；IP、Key、Hash、摘要等需要强调的内容改用 600 字重加粗区分
- **设置页**：按 1–4 分节卡片化，统一 12px 圆角、14px 内边距；表格去掉粗边框改为细线分隔；最近查询的摘要块改为 10px 圆角、等宽留白

## 1.0.2 — 2026-10-24

图标重绘，并包含 1.0.1 的全部安全加固 (1.0.1 未单独发布，内容并入本版)。

- 插件对外名称改为 **`LGSRC · 微步情报查询`**(英文 `LGSRC · ThreatBook Intel`)，设置页、面板与插件列表统一；描述中补充“由灵糕中心 · 安全响应中心维护”
- 插件图标重绘为盾形徽标：盾牌轮廓 50×55.6(略高于宽的经典比例)，**左右红蓝严格各占一半**，用 `#BC2A35→#7E1017` / `#336FBE→#143464` 竖向渐变 + 白色十字，去掉方形底板，16px 起各尺寸均清晰
- 本机 UI 路由 (`/threatbook/state`、`/threatbook/action`) 改为只接受 DSH 已授权浏览器的请求：未授权访问直接返回 `401`，同机其他进程无法读取网卡 IP / Key 掩码，也无法写入或清除 Key
- `open-report` / `open-folder` 收紧为只允许本插件 `threatbook-reports/` 目录内的文件与目录，避免被诱导打开任意路径
- 授权失效时面板提示「请刷新页面」，替代原先笼统的 HTTP 错误

## 1.0.0 — 2026-10-24

首个版本。

- 启动即读取本机网卡 IP 与公网出口 IP，面板可一键复制，便于在微步「我的 KEY」中绑定白名单
- 未配置 Key 时自动打开微步 KEY 绑定页并给出三步引导 (每进程仅自动打开一次)
- API Key 仅写入本机 `<profile>/plugin-data/threatbook-intel/apikey.json`(0600)，不上传、不进入模型上下文
- 自动识别输入类型 (IP / 域名 / MD5·SHA1·SHA256 / URL / CVE-XVE 等) 并执行多接口完整查询：
  - IP：`ip/query` + `scene/ip_reputation` + `ip/adv_query`
  - 域名：`domain/query` + `domain/adv_query` + `domain/sub_domains` + `scene/ioc` + `scene/domain_context`
  - 文件：`file/report`(summary / multiengines / signature / static / network / dropped / pstree / strings)+ `file/report/multiengines`
  - URL：`url/report`，无报告时自动 `url/scan` 并轮询
  - 漏洞：`vuln`(VPR / CVSS / PoC / 修复方案 / 补丁 / 在野利用)
- 每次查询落盘完整原始 JSON 与完整 Markdown 报告到工作区 `threatbook-reports/`
- 提供 `threatbook_lookup`、`threatbook_status` 两个工具；面板支持「AI 总结」「打开报告」「打开目录」
- 设置页提供全部网卡 IP、绑定说明、Key 更换 / 清除 / 连通性测试
